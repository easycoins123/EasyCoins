# EASYCOINS

פרויקט זה נוצר עם [Angular CLI](https://github.com/angular/angular-cli) גרסה 16.2.16.

## שרת פיתוח

הפעל `ng serve` עבור שרת פיתוח. נווט ל-`http://localhost:4200/`. האפליקציה תיטען מחדש אוטומטית אם תשנה את קבצי המקור.

## יצירת קוד

הפעל `ng generate component component-name` כדי ליצור קומפוננטה חדשה. אתה יכול גם להשתמש ב-`ng generate directive|pipe|service|class|guard|interface|enum|module`.

## בנייה

הפעל `ng build` כדי לבנות את הפרויקט. תוצרי הבנייה יישמרו בתיקיית `dist/`.

## הרצת בדיקות יחידה

הפעל `ng test` כדי להריץ את בדיקות היחידה באמצעות [Karma](https://karma-runner.github.io).

## הרצת בדיקות קצה לקצה

הפעל `ng e2e` כדי להריץ את בדיקות הקצה לקצה באמצעות פלטפורמה לבחירתך. כדי להשתמש בפקודה זו, עליך קודם להוסיף חבילה שמממשת יכולות בדיקה קצה לקצה.

## עזרה נוספת

לקבלת עזרה נוספת על Angular CLI השתמש ב-`ng help` או בדוק את [סקירת Angular CLI ומדריך הפקודות](https://angular.io/cli).
